# PixelForge AI 软件需求规格（MVP）

版本：0.1  
目标平台：Windows 10/11 x64  
产品形态：本地优先的 AI 生图桌面软件

## 1. 产品目标

为电商运营、服装商家和视觉设计人员提供一个可批量复用的生图工作台。用户可导入服装图、侧面图和面部参考图，用结构化标签组合提示词，通过兼容的生图 API 并发生成图片，并在本地管理任务、模板、素材与结果。

首版成功标准：新用户完成 API 配置后，能在一个界面内创建任务、导入参考图、生成至少一张图片，并在本地画廊中再次找到图片及其生成参数。

## 2. 用户与场景

- 电商运营：对同一商品批量生成不同动作、背景、构图和画幅的商品图。
- 服装商家：以服装参考图为约束，生成不同模特和展示角度。
- 视觉设计人员：保存高频提示词模板，快速复用并追溯生成参数。

## 3. MVP 功能范围

### 3.1 生成工作台

- 单图、多批次两种工作模式。
- 一个批次可包含多个任务；支持新增、复制和删除任务。
- 每个任务支持服装图、侧面服装图、面部图三类参考图。
- 支持方向、品类、画幅、清晰度、数量等结构化参数。
- 支持动作、构图、表情、发型、妆容、背景、摄影参数等提示词维度。
- 自动组合提示词，同时允许用户手工修改最终提示词。
- 批次任务不设置应用级并发上限，失败任务互不影响，并展示逐项进度。

### 3.2 API 设置

- 生图服务固定接入 `https://mianyunai.com/v1`，用户只配置 API Key 和模型名。
- 支持同步与异步调用模式，默认异步；异步任务提交后轮询任务状态并自动下载结果。
- API Key 不进入前端 localStorage；在系统支持时使用 Electron `safeStorage` 加密后落盘。
- API 超时、鉴权失败、限流和格式异常必须转换为可读错误。

### 3.3 本地数据

- 草稿、设置、素材索引、模板、任务记录和生成历史均保存在 Electron `userData` 目录。
- 导入参考图时复制到应用素材目录，避免原文件移动后失效。
- API 返回图片下载到本地输出目录；历史记录保存提示词、模型、参数、时间和文件路径。
- 支持从软件内打开输出目录。

### 3.4 资产与记录

- 素材库：查看已导入参考图。
- 画廊：查看生成结果、状态和关键参数。
- 任务记录：按批次查看成功/失败数量。
- 模板：保存和应用提示词模板。

## 4. 非功能需求

- 安装包：输出 Windows NSIS `exe` 安装程序，支持自选安装目录和桌面快捷方式。
- 性能：1000 条历史以内启动后 2 秒内展示主界面；生成任务不得阻塞界面交互。
- 可靠性：每张图片完成后立即写入历史，软件异常退出后已完成结果不丢失。
- 隐私：除用户配置的生图 API 外不连接其他业务服务器，不上传统计数据。
- 可维护性：API 服务、持久化和界面通过 Electron IPC 解耦，后续可增加 Gemini、火山、阿里云等适配器。

## 5. 明确不进入 MVP

- 用户账号、云同步、团队协作、在线支付。
- 复杂抠图、局部重绘、画布编辑器。
- 自动贴标、商品详情页编排、3D 服装建模。
- 模型训练、LoRA 管理与本地 GPU 推理。

这些能力进入第二阶段评估，首版保留扩展入口但不伪造不可用功能。

## 6. 核心数据模型

- `AppSettings`：加密密钥、同步/异步模式和默认模型。
- `GenerationTask`：任务名称、参考素材、结构化参数、最终提示词、数量。
- `AssetRecord`：素材 ID、文件名、本地路径、类型、导入时间。
- `GenerationRecord`：所属批次与任务、状态、模型、提示词、本地输出路径、错误、耗时。
- `BatchRecord`：批次标签、开始/完成时间、任务数量、成功/失败数。
- `PromptTemplate`：名称、基础提示词、默认维度与创建时间。

## 7. 交付阶段

1. MVP 骨架：需求、桌面壳、主工作台、本地草稿。
2. 可用闭环：API 适配、任务队列、本地图片、画廊与错误处理。
3. 生产增强：模板编辑、批量导入、结果筛选、参数复用、安装包验收。
4. 领域扩展：贴标、详情图编排、抠图/局部编辑、3D 相关能力。

## 8. 验收用例

1. 配置 API Key 后创建 2 个任务、每任务 2 张；应同时提交 4 个请求，结果在任务下方和画廊中可见。
2. 导入三类参考图后重启软件；草稿和缩略图仍存在。
3. 配置兼容 API 后生成图片；输出文件和完整参数写入本地历史。
4. 单个请求失败时其余任务继续，批次结果显示失败原因。
5. 执行 `npm run package:win` 后得到可安装的 `exe`，安装后无需开发环境即可启动。
